## Добавить новую работу

1. Положите готовую статическую копию сайта в `demos/имя-проекта/`. Для React/Vite нужна собранная версия с путями, подходящими для этой папки, а не исходный `src/`.
2. Добавьте изображение в `assets/previews/` и запись в `projects.json`. Категории: `sites`, `mini`, `graphics`.
3. Выполните `node scripts/build.mjs`. Команда обновляет главную страницу, количество работ, фильтры и просмотрщики графики. Сборщик требует Node.js, дополнительных пакетов нет.
4. Сохраните изменения в `main` и отправьте на GitHub. GitHub Pages опубликует обновленную галерею. Кнопка в портфолио продолжит вести на тот же адрес.

Графика и варианты изображений перечислены в `collections.json`. Перед добавлением клиентской работы проверьте разрешение на публикацию и права на материалы.

Для локального просмотра можно запустить статический HTTP-сервер. Галерея и простые HTML-сайты также открываются из файлов. Копия SIPPOP рассчитана на адрес `/works/demos/sippop/` на GitHub Pages.

Исходные проекты хранятся отдельно; папка `demos/` содержит их копии для просмотра. Обновление исходного проекта само по себе не заменяет копию: после изменений нужно обновить соответствующую папку.
